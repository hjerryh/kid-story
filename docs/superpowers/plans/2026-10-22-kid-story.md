# 小小故事岛 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Build a usable Chinese illustrated fairy-tale app for ages 3–10 with six complete stories and synchronized recorded narration.

**Architecture:** Expo / React Native supplies native iOS and Android apps and a browser preview. Bundled story JSON, rendered original illustrations and recorded narration share a page timeline; one application-level audio controller owns playback, and local persistence owns favorites, preferences and reading progress.

**Tech Stack:** TypeScript, Expo, React Native, react-native-web, expo-audio, AsyncStorage, react-native-svg, Node test runner via tsx, ffmpeg and a local asset-generation script.

**Spec:** `docs/superpowers/specs/2026-10-22-kid-story-design.md`

## Global Constraints

- 面向 3–10 岁孩子；内容主要是童话故事；故事中穿插故事插图，文字为辅；支持故事播放。
- 首版 6 篇完整原创童话，每个年龄段 2 篇；简体中文、普通话。
- 3–5 岁目标 2–4 分钟；6–8 岁目标 5–7 分钟；9–10 岁目标 8–12 分钟。
- 本地素材离线可用；一个故事一条完整音轨；一页一个同步时间区间；同时只允许一篇故事发声。
- 不自动发声；暂停时翻页保持暂停；播放中翻页从目标页继续。
- 支持本篇结束、15 / 30 分钟停止；支持后台播放、锁屏播放/暂停、音频中断及拔下耳机暂停。
- 不以系统即时朗读作为正式配音交付；不用重复封面代替故事插图。
- 原生行为必须记录实际验证环境，网页成功不等同于 iOS / Android 验收。

## Review Focus

- 快速切换故事或连续翻页：旧的异步加载不得覆盖新故事或产生双音轨；Task 3 测试操作序号与播放归属。
- 损坏或旧版本本地进度：不能崩溃或跳出故事；Task 2 测试迁移与范围校验。
- 音频边界与故事结尾：正确切页，结束停止，重播回开头；Task 2/3 测试边界。
- 后台计时与中断：恢复时按真实时间核对，界面反映真实播放器；Task 3/5 实测。
- 小屏幕和大字号：图片不遮住文字，控制可点击；Task 5 检查 390px 宽及桌面布局。

## Files and contracts

- `App.tsx`：providers 与故事库、阅读器、收藏的轻量导航。
- `src/content/stories.json`：原创故事正文与分页场景信息。
- `src/content/types.ts`：Story、StoryPage、AgeBand、SavedProgress 类型。
- `src/content/catalog.ts` / `assets.ts`：合并故事、音频时间轴、静态 require 素材映射。
- `assets/stories/<id>/page-XX.png`、`cover.png`、`narration.mp3`：可打包的真实内容。
- `src/content/timings.json`：音频实际时长与页面起止时间。
- `scripts/render-illustrations.mjs`：原创矢量绘本场景渲染 PNG，角色与色板保持一致。
- `scripts/generate-audio.py`：按页生成普通话配音，拼接为完整故事并写时间轴。
- `scripts/build-catalog.mjs` / `scripts/validate-content.mjs`：生成静态映射，检查所有素材和时间轴。
- `src/state/progress.ts` / `library.tsx`：纯进度逻辑、本地存储、收藏、年龄选择。
- `src/audio/controller.ts` / `PlaybackProvider.tsx`：纯控制逻辑与真实播放器集成。
- `src/ui/theme.ts` / `components.tsx`：暖白、松绿与杏色的绘本视觉、可访问按钮等。
- `src/screens/LibraryScreen.tsx` / `ReaderScreen.tsx`：选故事、阅读和播放器。
- `tests/*.test.ts`：有意义的时间轴、恢复与竞态测试。
- `docs/verification.md` / `README.md`：启动方法、验证证据和未验证的原生范围。

`AgeBand = '3-5' | '6-8' | '9-10'`。Story source fields: `id, title, subtitle, description, ageBand, theme, color, character, pages[]`。Page fields: `id, text, scene`；scene 至少包含 `setting, action, mood, props[]`，用于生成与情节对应的插图。

Story IDs: `moon-post`, `seed-light` (3–5), `cloud-whale`, `fox-library` (6–8), `clock-forest`, `wind-map` (9–10)。每页正文是真正被朗读的正文；较长页在界面里滚动，不藏到另一份未经朗读的摘要后面。

## Self-review and execution choice

Each design section is covered by content, state, playback, UI and verification tasks. Native checks intentionally remain distinct from browser checks. The local timer's background limitations require testing and an honest documented result. The six-story scope and all original explicit requirements are retained.

Execution: continue in this session. The main agent implements the app while independent agents handle content, illustration and audio production under the shared contracts; a fresh reviewer checks the integrated result. The user's “继续” authorizes continued work, and routine delegation choices are made by the implementer.
